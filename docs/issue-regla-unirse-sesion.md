# Issue: ¿Puede unirse a la sesión de estudio?

**Estado:** Cerrado (Implementado y verificado)

## Historia de usuario

Como estudiante, quiero unirme a una sesión de estudio para participar y repasar la materia con mis compañeros.

## Criterios de aceptación

- [x] Solo se permite unir a la sesión si su estado es "abierta".
- [x] Una sesión "cerrada" no acepta nuevos participantes.
- [x] Un estudiante no puede inscribirse dos veces a la misma sesión.
- [x] La inscripción permanece después de recargar.
