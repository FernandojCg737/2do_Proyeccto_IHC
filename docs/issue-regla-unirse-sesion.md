# Requisito docente · Unirse a una sesión de estudio

> Relacionado con: GitHub Issue #1

## Historia de usuario

Como estudiante,  
quiero unirme a una sesión de estudio,  
para estudiar con otros la materia que necesito.

## Criterios de aceptación

- [x] Puedo unirme a una sesión **abierta**, con cupos y con fecha futura.
- [x] No puedo unirme a una sesión **cerrada**.
- [x] No puedo unirme si la sesión **no tiene cupos**.
- [x] No puedo unirme a una sesión cuya **fecha ya pasó**.
- [x] No puedo unirme dos veces a la misma sesión.
- [x] El creador no puede unirse a su propia sesión.
- [x] Cuando la acción está bloqueada, la interfaz explica el motivo.
- [x] La inscripción se guarda en la base de datos y se mantiene después de recargar.
- [x] Hay pruebas unitarias de la regla: al menos un caso permitido y un caso rechazado.
